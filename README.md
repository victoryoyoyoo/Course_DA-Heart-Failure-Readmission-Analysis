# Heart Failure Readmission Analysis & Machine Learning Pipeline

A robust machine learning pipeline for predicting 30-day heart failure readmissions using clinical data, featuring missingness diagnostics, advanced imputation, feature selection, SVR, Random Forest, and Deep Autoencoders.

## 🛠️ Tech Stack
* **Python 3.10**
* **Data Processing & ML**: Pandas, NumPy, Scikit-Learn, TensorFlow/Keras
* **Diagnostics & Visualization**: Matplotlib, Seaborn, Missingno
